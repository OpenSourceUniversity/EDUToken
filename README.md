# ![Logo](edu-logo.png) [OS.University](https://os.university) - EDU Token

EDU token contract that powers the OS.University Network

> **Archived, no longer maintained.** This repository holds the EDU token contract of the 2017 to 2020 OS.University network. It is no longer developed and its development dependencies are out of date.
>
> The project continues as **[The Open Source University Foundation](https://opensourceuni.org)**, which issues **Open Source Diplomas™** as electronic attestations of attributes for European Digital Identity Wallets and as signed PDF documents. Open Source Diplomas do not use a token or a blockchain, and the Foundation does not issue or sell any token.
>
> * Website: https://opensourceuni.org
> * Portal: https://portal.opensourceuni.org

## Prelude
OS.University (Open Source University)  is world’s first distributed academic & career development ledger, with potential to transform the way 7 billion people develop academically and grow professionally.
